# Проверка центральных виджетов — 14 ноября 2026

> Исторический документ: центральные виджеты отменены в версии 0.3.0. Текущий интерфейс показывает только приборку; настройки `widgets`, кнопки выбора и описанное ниже переключение больше не входят в приложение. Исследование источников сохраняется как архив и не подтверждает их работу на BMW пользователя. Актуальная конфигурация — [CONFIGURATION.md](CONFIGURATION.md).

## Проверено автоматически

`npm test` — успешно, журнал `artifacts/widgets-tests.log`. Проверяются реальные модели/отрисовка и runtime приложения, а не отдельная HTML-приборка:

- Строгая схема6 и атомарная миграция1–5 с сохранением параметров; сохраняется только выбранный id, без показаний автомобиля.
- Технические кнопки iDrive вызывают тот же `selectWidget`/`nextWidget`; нет автоматического открытия страницы, нового фонового runtime или автозапуска. «Выключить отображение» сохранено.
- Выбор не меняет сигналы, переиспользует HUD, не добавляет подписки/таймеры. Прежняя защита при потере критичных данных действует и во время виджета.
- Шесть полей скорости/передачи становятся прозрачными и восстанавливаются; смена выбора сразу обходит ограничение частоты обновления данных. Явный выбор обычной приборки сбрасывает сохранённый виджет и в архивном режиме.
- Каждое значение TPMS независимо, с проверкой качества, источника, единиц и допустимости; нулевое давление остаётся нулём. Metric/US, отрицательная/трёхзначная температура, полный пробег и ширина единиц проверены.
- Музыкальная модель ограничивает размер обложки/текста; невалидное и stale очищаются. Изменение того же буфера обложки обнаруживается, пиксели не включаются в ключ кеша. Позиция воспроизведения не вычисляется по времени. Положительный объект — только синтетический unit-test, не данные CarPlay.
- Python:14 контрактов упаковки/логов; статический ES2017/API контроль:63 автомобильных JS-файла. Исполнение на реальном Node8 недоступно и не заявляется.

## Проверено на локальном стенде

Проверка `BENCH_PORT=8090 node bench/verify-widgets.js` использует отдельно запущенный стенд8090 с фиксированными основными значениями и временем14:36. Внешняя панель управляет тем же процессом приложения, что рисует шрифтовые ресурсы автомобильной сборки.

Отчёт — `artifacts/widgets-verification.json`; чистые PNG1920×720 — `widget_tyres.png`, `widget_music.png`, `widget_navigation.png`, `widget_vehicle.png`. Запись переключения — `widgets-switching.webm`.

Проверены ручной выбор, отсутствие автоматического листания, неизменность пикселей вне центральной области, восстановление обычного кадра, скрытие скорости/передачи без изменения самих сигналов. Отдельное отсутствующее колесо, потеря/возврат TPMS, критичная потеря, сон/пробуждение, renderer reconnect и перезапуск с сохранённым выбором проверяются через транспорт стенда. Слой виджета не пересоздаётся при обычном выборе.

План:21 слой,4 соединения;6 313 000 байт изображений с двойным учётом против консервативного общего лимита16MiB;12 подписок,6 интервалов. Новый image-layer стоит780×290×8 =1 809 600 байт. Это не измерение полной памяти MGU.

Финальный прогон дополнительно проверил24 маски исходных глифов в US: давление PSI, температуры−40/302°F, подписи МИЛЬ/GAL без усечения. Ошибка сохранения выбора возвращается через подтверждение приложения и видна вне холста; успешная следующая команда снимает её. Видео декодировано как1920×720. Ошибок JavaScript в браузере нет. Основные четыре снимка просмотрены визуально: подписи помещаются, единицы читаются, скорость/передача отсутствуют только в центре виджетов.

Рабочий локальный сервер8078 обновлён; введённые сигналы, FES, availability, состояние renderer, конфигурация и выбранный экран сохранены и сверены. Новый `/widget` проверен командой выбора уже текущего экрана. Результат — `artifacts/widgets-live-verification.json`. Это локальное обновление, не перезапуск MGU.

На музыкальном и навигационном снимках показано честное отсутствие источников. Их наличие в переключателе не означает работающий плеер CarPlay или карту Яндекса.

## Требует автомобиля или дополнительного источника

Реальные TPMS/единицы/пробег на этой G30, кнопки технической страницы на настоящем RHMI, физическая BC, источник музыки/обложки/позиции и карта Яндекс Навигатора не проверены. Штатные предупреждения и безопасное постоянное место скорости/передачи тоже требуют отдельной проверки. Пока при виджетах скорость/передача скрыты, дорожное использование этой компоновки не рекомендуется.

Подключений к автомобилю, установки, изменения BMW-процессов, патчей CarPlay или управления воспроизведением не было. Source bundle содержит исходники; устанавливаемый автомобильный пакет без настоящего SDK не получен. При выключении приложения освобождаются только его слои; без автомобильной проверки это не гарантия восстановления штатной картинки при любом отказе.
