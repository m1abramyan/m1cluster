# Проверки Retro Cluster 0.3.0

Дата: 14 ноября 2026. Публичный источник: `m1abramyan/m1cluster`, ветка `main`. Идентификатор остаётся `manuk_retro_cluster`.

## Реализовано

- Центральные виджеты и ручное переключение удалены. Приборка постоянно показывает скорость и передачу; ранее согласованные геометрия, цвета, тахометр и боковые шкалы сохранены.
- Настоящие RHMI-экраны MAIN, LANGUAGE и UNITS: включение отрисовки, ожидание запуска двигателя, RU/EN, отдельные единицы скорости/расстояния, температуры, давления и расхода. Страница сама не открывается.
- Схема 7 и атомарная миграция 1–6. Удаляется только устаревший выбор виджета. Настройки хранятся отдельно; значения автомобиля не сохраняются как текущие.
- Engine gate читает подтверждённый `CDS.statusEngineStatus.statusEngineRunDrive`, не выводит запуск из RPM. В одном активном сеансе сохраняет разрешение при stop/start; неизвестное состояние, сон, потеря источника и новая эпоха его сбрасывают. Новых опросов и таймеров нет.
- Иконка 140×140 с оригинальными DSEG-цифрами и цветами тахометра. Лицензии сохранены.

## Проверено автоматическими тестами

`npm test`: конфигурация, строгая валидация, миграция, сохранение/перезапуск, 16 сочетаний единиц, реальные токены HUD, независимость состояний, свежесть сигналов и потери источников, engine gate, lifecycle и очистка подписок/таймеров. Тест реальной ошибки атомарной записи подтверждает освобождение слоёв и невозможность повторного включения остановленного контроллера.

Упаковка проверяется в явно маркированном bench-stage: реальные RHMI XML/JSON, отдельная точка входа, 17 компонентов, настройки с Unicode, неизменность icon.png в обоих наборах ресурсов, итоговое `mguAppStartType: manually`. Запрет выпуска автомобильного пакета без SDK/с заглушкой, перенос opt-in autostart в итоговые метаданные и собственный Store catalog проверены отдельно.

Статический контроль 64 автомобильных JS-файлов: ES2017 и используемые API. Это не запуск на Node 8. Полный локальный журнал — `artifacts/release-0.3.0-tests.log` (не публикуется вместе с пользовательскими журналами).

`bench/verify-idrive.js` на отдельном порту: настоящие действия RHMI включают/выключают слои; скрытые/неверные компоненты отклоняются; язык и четыре группы единиц сохраняются. По пикселям оригинального атласа проверены 18 числовых строк: 55 mph, 280 mi, 212/194 °F, 11.6 psi, 30.9 MPG US при неизменных исходных показаниях. Проверены engine off → running, stop/start, сон/пробуждение и перезапуск до первого создания HUD.

## Проверено визуально на стенде

Снимки `artifacts/idrive_settings_ru.png`, `idrive_settings_en.png`, `idrive_units.png`, `idrive_units_en.png`, `idrive_engine_waiting.png`: подписи помещаются, чекбоксы отражают сохранённые значения. `idrive_units_cluster.png` — реальная приборка после переключения единиц. Изображения страницы iDrive — локальный RHMI-предпросмотр, не фотография BMW.

После удаления виджетов: 20 графических слоёв, четыре соединения 3/3/7/7, 4 503 400 байт с двойным учётом image-памяти; лимиты 32 общих слоёв, 8 на соединение и 16 MiB не превышены. Число подписок/интервалов проверено до и после перезапусков.

## Требует проверки на автомобиле

- Установка/сборка Store с настоящим SDK, фактическое исполнение Node 8.16.2 и API конкретного HU.
- Native RHMI: внешний вид, фокус, контроллер iDrive, языки и checkbox callback конкретного SDK.
- Реальный CDS engineRunning на этой G30, работа в фоне, уход в сон, восстановление и ручной запуск после полного выключения.
- Пригодность speed/gear/FES/температур/уровня топлива/запаса хода; отдельные данные DSC, наддува и расхода пока не подтверждены. Синяя полоса скрыта без подтверждённого источника.
- Видимость штатных предупреждений и штатной скорости; отключение и восстановление изображения. Полноэкранная Retro может закрывать штатные области.

**С автомобиля ничего не читалось.** Устанавливаемого пакета с настоящим SDK локально нет. Первый выпуск ручной и выключен по умолчанию. Флажок запуска двигателя влияет только на отрисовку в уже запущенном процессе; полноценный автозапуск — отдельный opt-in пакет после стояночного теста. До проверки штатных предупреждений, скорости, передачи и отключения дорожный тест не рекомендуется.

## Состав публикации

Неиспользуемый `kit/emu/` и его launcher `kit/tools/emu.js` исключены из публикации и Store-архива. Это другой эмулятор mgu-renderd с WebAssembly, не задействованный нашим cluster-render стендом. Его локальный оригинал сохранён; автомобильная сборка и наши проверки от него не зависят. В публикацию входят только выбранные исходники и изображения, без SDK, локальных журналов, файлов состояния и копий upstream.
