# Проверки исходного переноса 0.1.0 — 14 ноября 2026

Это исторический отчёт точного переноса и русской локализации. Актуальные проверки трёх профилей 0.2.0 — в [PROFILES_VERIFICATION.md](PROFILES_VERIFICATION.md); число слоёв, подписок и политика неподтверждённого boost там обновлены. Исходные reference_retro.png / retro_cluster.png / diff.png сохранены.

## Проверено автоматическими тестами

`npm test` исполняет конфигурационные/ресурсные проверки, **20 runtime/lifecycle сценариев**, **11 контрактов упаковки**, **3 проверки очистки логов** и проверки русской локализации. Статический контроль после добавления локализации прошёл для **59 JavaScript-файлов**: ES2017 и распространённые API, появившиеся после Node 8.

Проверены:

- Строгая схема, отказ неизвестным полям/темам/типам/диапазонам, числовой UTC+240, `tankLitres:null`, отсутствие Demo API.
- Атомарное сохранение, права 0600, восстановление настроек после повторного создания runtime, отказ повреждённому JSON без его перезаписи, отсутствие лишних config watcher.
- Побайтная идентичность одной Retro layout и восьми font JSON исходному commit. Отдельно сравнены исходные hud.js/hud_text.js/hud_themes.js/shaders.js/cluster_render_client.js.
- Нули, недоступные и invalid значения, неизвестная/дробная передача, отсутствие вычисленной передачи после множества speed/rpm наблюдений.
- Смена доступности источника, истечение подтверждения speed/rpm, сохранение неизменных событийных значений в пределах периода доступности, игнорирование поздних ответов и уведомлений после потери источника.
- Off/unknown VehicleCondition и потеря его провайдера инвалидируют данные предыдущего периода работы. Возврат требует новых speed/gear.
- Настоящий RetroHud с исходным движком: отсутствующие RPM не остаются в сглаженном кеше; неизвестные топливо/впуск недоступны; освобождаются все четыре соединения, listener/watcher не остаются после stop; автоматическая запись обучения переключений отключена.
- Настоящий изменённый mgu.js с тестовым SDK: background работает без RHMI, SDK initialization завершается, shutdown останавливает фон до выхода. Это проверка программного контракта, не SDK автомобиля.
- Задержка источников, повторные start/stop, disable/re-enable, отсутствие повторяющегося запуска после ошибки конструктора.
- Только собственный id и одна техническая RHMI страница, read/subscribe signal permissions без TASU, отсутствие других layouts и декоративного брендинга на холсте.
- Build отказывается при отсутствующем SDK и известном stub; bench staging явно помечен и не создаёт устанавливаемых архивов. `manually` и явный `autostart` проверены в конечном package.json **bench-stage**. Настоящий автомобильный архив не получен. Wrapper для будущей реальной сборки проверяет архив после создания.
- Лицензии/авторство сохраняются в staging; Store manifest предлагает только manuk_retro_cluster ID7, не содержит сетевых или установочных hooks.
- `tests/locale.test.js`: русские статусы технической страницы — недоступные данные, освобождение слоёв, подключение, ожидание, ошибки и точные числа слоёв/соединений/памяти. Исходные сообщения протокола и журнала не изменяются. Проверено сохранение русских статических RHMI текстов в UTF-8 StringBundle при сборке; для динамической кириллицы используется существующий путь StringId.
- `tests/dashboard-locale.test.js`: русские подписи всех доступных дополнительных полей и единиц имеют глифы в атласах и помещаются в исходные области. Координаты, размеры, отступы, палитра и все DSEG-виджеты сохранены. Локализация не меняет исходный JSON; `language: "en"` возвращает оригинальный layout, а существующая конфигурация без поля языка получает русский интерфейс без сброса других параметров.
- Для `ru_head` и `ru_unit` проверены размер alpha-данных и покрытие символов, при генерации — наличие глифов в cmap шрифта и ширина подписей. Roboto Condensed SemiBold взят из зафиксированного commit Google Fonts, SHA-256 TTF/лицензии/атласов записаны в `artifacts/russian-font-provenance.json`. Исходные числовые атласы не перегенерировались.

`node bench/verify.js` проверяет реальный процесс приложения через локальный имитатор протокола renderer: задержка готовности, отключение/восстановление, три цикла disable/enable, нули, верхние тестовые значения, отсутствие данных и сохранение disabled после перезапуска. Результат — `artifacts/bench-verification.json`. На циклах не растёт число подписок/интервалов: шесть signal subscriptions и семь интервалов вместе со служебными интервалами стенда.

Бюджет фиксированного Retro: 14 слоёв, распределение 3/2/6/3; 5 503 120 bytes изображений при консервативном лимите 16 MiB. Экранные тесты не измеряют полную RSS MGU-процесса или реальную GPU-память; их надо проверить на машине.

## Проверено визуально на стенде

Сначала запущен нетронутый оригинал `cluster_themes` на commit `aaa43e49500ccb4cd6b07537644ac072db49eb99`, затем выделено наше приложение. Настройки и постоянные исходные значения хранятся в `bench/fixture.json`, JSON нашей конфигурации — `artifacts/comparison-config.json`. Часы зафиксированы 14:36 только в bench loader; настоящее время lifecycle не замораживается.

Одинаковые US/12h настройки **английского эталонного режима (`language: "en"`)**: исходная скорость 88 км/ч → 55 MPH, передача 4, 3200 rpm, масло 100°C → 212°F, охлаждение 90°C → 194°F, boost 0.8 bar → 11.6 PSI, топливо 40 из синтетических 65 л → 62%, впуск отсутствует. Время на холсте 2:36. Night dim и stripClear выключены, размеры 1920×720.

Числа сравнения — `artifacts/visual-comparison.json`. Эталон и тест снимаются на одном Mac/Chrome renderer, после полной загрузки всех слоёв, без движущегося demo-сценария. Проверены координаты, палитра, исходные семисегментные атласы, подписи и оба дополнительных поля. Проверены внешние элементы управления/чистый экран/скачивание PNG — `artifacts/bench-ui-verification.json`. Контролы и «Имитация данных» не попадают в снимок.

После добавления русского языка повторно выполнено сравнение английского режима с первоначальным эталоном. Результат сохранён отдельно в `artifacts/localization-english-recheck.json`: нулевая разница и совпадающие SHA-256 PNG подтверждают, что перевод не изменил оригинальное отображение при `language: "en"`.

Нулевой diff относится к английскому детерминированному набору и точным настройкам; он не доказывает совпадение GPU разных устройств во всех состояниях. Русский вариант меняет только подписи и два атласа для них по явному запросу пользователя, поэтому его снимки не подменяют эталон и не участвуют в утверждении о нулевой разнице. На русских снимках визуально проверены читаемость, отсутствие обрезания подписей и сохранение оригинальных цифр/геометрии. Часы на этих снимках могут показывать текущее время стенда. Поведение при отсутствии данных намеренно отличается от оригинала в пользу освобождения дисплея/недоступности.

## Требует проверки на автомобиле

Ничего ниже не выполнено на BMW пользователя:

1. Совместимость текущих MainApp/SDK/Store, установка и конечный автомобильный архив; отображение русской технической страницы через StringBundle/StringId на реальном HMI.
2. Исполнение на Node 8.16.2. Здесь arm64 Mac, Node24.21.0; официальный Node8 darwin-x64 скачан локально и проверен по SHA-256, но запуск завершается Bad CPU type. Rosetta не устанавливалась; Docker daemon недоступен. Статический контроль не заменяет целевой запуск.
3. Доступность/enum/getter всех сигналов именно G30. Подписка передачи без getter после нового периода работы может консервативно ждать следующего настоящего события. Не обходить это Demo/догадкой.
4. Источник температуры впуска: автомобильная версия сейчас показывает недоступно. Подтверждённая ёмкость бака нужна для процента топлива. FES boost может отсутствовать; диагностических запросов нет.
5. Реальная видимая область panel, яркость/цвета, GPU загрузка, расход памяти/CPU и конкуренция за общий renderer.
6. Штатные предупреждения, скорость, селектор, возможные непрозрачные BMW оверлеи. Маска исходного bench измерена на другом автомобиле, X3; она не калибровка G30.
7. Реальное освобождение target и возврат штатной приборки при disable/потере данных/завершении процесса. Из протокола подтверждено удаление своих слоёв при drop/disconnect, но возможен linger и внешнее состояние дисплея.
8. Сон/пробуждение, отсутствие удержания машины активной, ручной запуск после сна. Автозапуск выключен и является отдельным этапом.

Точный эталон оставлен без скрытых сдвигов. `car-parked-strip.example.json` — отдельный экспериментальный вариант со штатной опцией stripClear, не гарантия безопасности предупреждений. Порядок проверки/выключения/удаления — `FIRST_CAR_TEST.md`. Дорожные испытания до подтверждения реальной индикации и предупреждений не рекомендованы.
