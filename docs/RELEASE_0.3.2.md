# Retro Cluster 0.3.2 — проверка показаний через iDrive

14 ноября 2026. Ручной пакет `manuk_retro_cluster`, `mguAppStartType: manually`. Автомобиль не подключался, устанавливаемый пакет с настоящим BMW SDK локально не получен. Владелец устанавливает обновление источника через существующий Store отдельно.

## Что изменено

В настройках появилась **«Проверка данных»**: явный запуск 30-секундного сбора, отмена, статус и страницы QR. Для сбора не требуется включать приборку или менять сохранённый `enabled`. Результат передаётся пользователем вручную: фотографии всех QR-страниц или скопированные сканером тексты. Автоматической отправки, HTTP-сервера и сетевых учётных данных нет.

Собираются исходные значения только семи полей пяти интерфейсов: KombiIF (литры/запас/БК1/БК2 и единица), FES (наддув и максимум), DSC (три qualifiers), CDS2 (счётчик впрыска и масло), ResetLogic (текущий/средний расход). Последние два поля читаются только при наличии безопасных числовых/enum-членов в локальных определениях. В manifest добавлены только `rs` для CDS2.statusInjectionVolume и ResetLogic.currentConsumption/averageConsumption; постоянный источник приборки их не опрашивает. Диагностические запросы ECU/UDS/OBD, setters и методы записи не добавлены.

Перед чтением проверяются наблюдённые скорость 0, P и активное состояние автомобиля. После принятого нуля неизменный событийный сигнал допускается только в том же поколении источников. Движение, не-P, сон, недействительные данные или потеря источника прекращают сбор. При необходимости выполняется один разрешённый getter скорости; нового периодического опроса нет. Отмена и завершение закрывают только собственные временные подписки. Ошибка/частичный сбор также доступны для передачи через QR.

Ограничения: до 30 секунд, до 121 снимка, отчёт до 256 KiB. Каталог допускается до 8 MiB, проверка размера происходит до выделения буфера и JSON-разбора; из него выводятся только выбранные описания. Превышение возвращает явное отсутствие метаданных, известные raw-поля остаются доступны. Это не жёсткий предел общей памяти процесса. Нативное синхронное зависание SOME/IP не может быть прервано обычным JS-таймером; watchdog и перезапуски BMW-процессов не добавлены.

`diagnostics-last.json` сохраняется атомарно с правами 0600 только в data-каталоге нашего приложения. QR содержит полный сохранённый по структуре отчёт, сжатый gzip; SHA-256 обнаруживает повреждение/смешивание страниц, но не доказывает подлинность автомобильных значений. До 64 страниц, без молчаливого усечения данных при упаковке QR. Если лимит истории достигнут, в самом отчёте есть счётчики пропусков. Стенд всегда помечен `bench`/`simulation`. QR-изображения создаются штатным RHMI-механизмом в собственных временных ресурсах приложения.

Исправлена отдельная ошибка топлива: если измеренные литры превышают явно заданную ёмкость, приборка показывает недоступность вместо ложных 100%. Подтверждённая ёмкость этой машины по-прежнему не задана автоматически. Геометрия, атласы, палитра, режимы и скорость не изменены.

## Что ещё неизвестно

Расход л/ч, топливо %, наддув в bar и DSC ON/TRACTION/OFF **не объявлены исправленными на G30**. У public upstream расход требует неизвестных членов/калибровки, проценты требуют ёмкости или прямого сигнала, boost отмечен q:true, DSC оставлен raw. Получение правдоподобного числа или перечисления само по себе недостаточно. Сбор не требует выключения DSC, перегазовок, включения D/R или движения.

[Инструкция через iDrive](DIAGNOSTICS.md) и [карта источников](DATA_SOURCES.md). Пакет не меняет политику автозапуска; проверка штатных предупреждений и возврата стандартного изображения остаётся обязательной до дорожных испытаний.

## Проверки

Автоматические проверки охватывают ограниченный каталог, приватность, состояния скорости/P/сна, отмену/повторный запуск, позднее завершение подписок, пределы отчёта, сохранение, смешанные/неполные QR, контрольную сумму и ограничение распаковки. На Mac независимый Apple Vision распознал все 8 настоящих PNG тестового отчёта; после восстановления полный JSON совпал побайтно по содержимому. Это проверка искусственных данных, не съём с автомобиля.

Выполняется ES2017/API-проверка 68 JS-файлов автомобильного кода. Реальное исполнение Node 8 и native SOME/IP на G30 не подтверждены. SDK-заглушка допускается только в bench: автомобильная сборка без настоящего SDK должна отказать.


Полный 30-секундный сценарий через настоящий код страницы iDrive проверен в изолированном стенде: отмена, отказ при движении, завершение, RU/EN, переход между страницами и экспорт частичного отчёта. Четыре QR-PNG именно этого запуска независимо распознаны Apple Vision; весь отчёт восстановлен без отличий. Подписки вернулись к исходным 12, интервалы — к 7; сцена сохранила 20 слоёв и 4 503 400 байт image-памяти. Синтетические Kombi/FES-значения собраны; DSC в этом стендовом запуске не подменялся придуманным raw-кодом. Положительные/неизвестные DSC raw проверены отдельно синтетическими unit fixtures. Порт тестового стенда закрыт, состояние пользовательского стенда 8078 не сбрасывалось.

Полный `npm test` прошёл: JS-набор, 19 Python-проверок упаковки/обезличивания и статический аудит 68 JS-файлов. `npm run build:car` ожидаемо отказал без настоящего SDK. Исходный ZIP 0.3.2 содержит диагностические модули, MIT-лицензию QR и локальный декодер; не содержит устанавливаемого `.tgz`/`.mgu`, SDK или заглушки.
