# Retro Cluster 0.3.3 — список диагностических значений

Ручной выпуск для `manuk_retro_cluster`, источник Store `m1abramyan/m1cluster`, ветка `main`. После сообщения владельца о пустом QR-экране способ просмотра заменён по его просьбе: **Проверка данных → Собрать данные · 30 с → Показать значения**. Фотографии всех страниц можно передать вручную. Приложение ничего не отправляет в интернет.

## Изменения

- Все пять экранов приложения используют нативные списки RHMI. Результаты содержат до четырёх двухстрочных пунктов на страницу, номер страницы и кнопки предыдущая/следующая/назад. Перелистывание ручное. Нет canvas, PNG, QR и центральной графической поверхности для диагностики.
- Показаны разрешённые исходные значения семи полей пяти источников: топливо/запас, BC1/BC2/код единиц, наддув/максимум шкалы, три DSC qualifier, счётчик впрыска/масло CDS2, кандидаты ResetLogic current/averageConsumption. Неизвестные поля остаются «нет данных». Описание полного списка — [DIAGNOSTICS.md](DIAGNOSTICS.md).
- Изменявшиеся значения имеют первое значение и min/max; у счётчика впрыска также число наблюдений и время первого/последнего значения. Таблицы enum показываются как определения каталога, без превращения их в неподтверждённые состояния автомобиля. Длинные имена разделены на строки. Лимит — 64 страницы с явным сообщением о пропусках; полный ограниченный отчёт остаётся в собственном каталоге данных.
- Сохранение отчёта и 30-секундный ограниченный сбор остались прежними. Частичный отчёт и уже собранные данные доступны при ошибке сохранения файла. Генератор QR и его библиотека удалены из автомобильного кода. Офлайн-декодер сохранён только для архивных отчётов 0.3.2.
- Исправлена упаковка обычных двухстрочных элементов меню: в реальном RHMI должны присутствовать `Text1stRow` и `Text2ndRow`, включая Unicode-ресурсы. Стенд показывает эти строки друг под другом.

В реальном runtime прежний canvas мог задействовать центральный Display renderer, хотя QR передавался как отдельное изображение. Локальный предпросмотр не воспроизводил этот путь. Это выявленная несовместимость путей в коде, а не доказанный по логам автомобиля диагноз. Новый экран вообще не инициализирует этот графический путь: тест использует настоящий конструктор Display и проверяет отсутствие renderer lookup, поверхности и его таймера.

## Выполненные проверки

Автоматические: полный `npm test`, упаковка пяти меню и правильных двухстрочных ячеек, реальные обработчики настроек, границы страниц, RU/EN, частичные/пустые отчёты, отсутствие вызова image/GPU, ограничения и очистка коллектора, совместимость с сохранёнными настройками. Статический контроль целевого ES2017/API проходит для 67 JS-файлов. Фактическое исполнение на Node 8.16.2 не проверено: доступная среда Mac arm64/Node 24.21.0.

Изолированный стенд на loopback-порту 8092: 30-секундный сбор, отмена и отказ при движении, **13 страниц** полученного синтетического отчёта, точное совпадение всех строк с форматтером, RU/EN, навигация до границ. Число страниц реального отчёта зависит от ответов и каталога. После сбора временные подписки и таймеры освобождены. Приборка сохраняла 20 слоёв, 4 503 400 байт изображений, геометрия не менялась. Пользовательский стенд 8078 не использовался как тестовый.

Визуально просмотрены текстовые страницы топлива и единиц расхода; [пример топлива](../artifacts/diagnostic_values_ru_page03_SIMULATION.png), [пример единиц](../artifacts/diagnostic_values_ru_page05_SIMULATION.png). Это имитация на Mac, не реальные данные автомобиля и не точное воспроизведение размеров штатного меню BMW. На MGU могут потребоваться прокрутка и дополнительные фотографии строк.

`npm run bundle:source` создаёт исходный архив 0.3.3 для Store. Без настоящего SDK `npm run build:car` отказывает. Тестовая заглушка не может выпускать устанавливаемый пакет. `mguAppStartType` остаётся `manually`; существующие настройки владельца не сбрасываются.

## Что требует автомобиля

Новая страница и её читаемость на MGU, доступность полей, физические единицы/масштабы расхода и наддува, семантика DSC, подтверждённая ёмкость бака. В этом выпуске расшифровка четырёх отсутствующих показателей не объявляется исправленной. С G30 ничего не прочитано и на неё ничего не установлено ассистентом. Перед движением по-прежнему нужны проверки штатных предупреждений и возврата штатной приборки; автозапуск не включён.
