# Центральные виджеты

> Исторический документ: центральные виджеты отменены в версии 0.3.0. Текущий интерфейс показывает только приборку; настройки `widgets`, кнопки выбора и описанное ниже переключение больше не входят в приложение. Исследование источников сохраняется как архив и не подтверждает их работу на BMW пользователя. Актуальная конфигурация — [CONFIGURATION.md](CONFIGURATION.md).

В адаптированной Retro есть пять состояний: обычная приборка и четыре виджета. Выбор меняет только отображение; скорость, передача, FES и DSC в источнике остаются прежними. Автоматической карусели нет.

| Выбор | Содержимое | Текущая доступность |
|---|---|---|
| Приборка | Прежние скорость и передача, подписи единиц и КПП | Исходное поведение приложения |
| Шины | Давление и температура каждого из четырёх колёс | Используются существующие нормализованные TPMS с отдельным качеством для каждого показателя; отсутствие единиц/источника даёт прочерки |
| Музыка | Место обложки, название, исполнитель, альбом, позиция и длительность, линия времени | Подготовлена отрисовка; реального источника метаданных/обложки/позиции в исследованных исходниках не найдено, поэтому обычное приложение показывает «нет данных» |
| Навигация | Место для Яндекс Навигатора из CarPlay | Карта недоступна. Найденные подсказки поворотов не являются видеопотоком карты; они в эту версию не подключены |
| Автомобиль | Полный пробег, наружная температура, запас хода, количество топлива | Используются имеющиеся источники; неизвестное не заполняется паспортными или демонстрационными числами |

## Управление

На локальном стенде снаружи холста доступны пять кнопок и переход назад/вперёд. На технической странице приложения в iDrive — пять вариантов и «Следующий виджет»; «Выключить отображение» сохранено. Эта страница не открывается автоматически. Это ручной выбор содержимого, без меню настроек или команд управления автомобилем.

Кнопка BC пока не подключена: в закреплённых исходниках не найдено подтверждённого события именно подрулевой кнопки. Готовый `RetroRuntime.nextWidget()` можно будет вызвать из будущего проверенного обработчика. Сам по себе этот метод не является интеграцией с BC. Контроллер iDrive, нажатие экранной кнопки и данные BC1/BC2 не используются как подмена BC. Исследование и процедура проверки — [BC_BUTTON.md](BC_BUTTON.md).

В конфигурации схемы6 сохраняется только выбор:

```json
"widgets": { "selected": "dashboard" }
```

Допустимые значения: `dashboard`, `tyres`, `music`, `navigation`, `vehicle`. Обновление со схем1–5 добавляет обычную приборку, сохраняя прежние настройки. Показания шин, треки и состояния автомобиля не записываются в конфигурацию. Выбор виджета не включает выключенное приложение и не включает автозапуск.

Запуск локального стенда из корня проекта:

```sh
npm run bench
```

Адрес: `http://127.0.0.1:8078/`. Если он уже работает, второй экземпляр на том же порту запускать не нужно.

## Отрисовка и ограничения

Область виджета — x620,y387,780×290 на холсте1920×720. Скорость, передача и их подписи скрываются на время показа виджета и возвращаются кнопкой «Приборка». Тахометр, боковые шкалы и независимо центрированная строка режима/DSC сохраняются. Новая позиция скорости и передачи намеренно не выбрана — это следующий согласуемый этап.

Используется один дополнительный переиспользуемый image-layer через прежний cluster-render. Рисует тот же код Node приложения: готовые русские атласы и исходные семисегментные цифры, без отдельного HTML-макета, системных шрифтов и новых графических сервисов. При смене виджета очищаются шесть прежних центральных текстовых полей и обновляются пиксели существующего слоя. Архивный режим оригинальной Retro не содержит новых виджетов.

Музыкальный прогресс не идёт по локальному таймеру: только полученная позиция/длительность. Нет сетевой загрузки обложек, guessed media API, кнопок управления воспроизведением автомобиля или патчей CarPlay. Положительные проверки музыкальной отрисовки используют явно синтетический тестовый объект и не подтверждают работу с телефоном. Отдельные музыкальные поля могут отсутствовать; неизвестное воспроизведение не объявляется паузой или остановкой.

Для шин не рассчитывается «нормальное» давление без штатных целевых значений. Некорректная температура отсекается по диапазону исходного приложения; допустимый нулевой уровень давления не скрывается. Единицы отображаются рядом с каждым значением. Пробег показывается полностью, а не тысячами километров под неверной подписью.

Пока виджеты скрывают скорость и передачу, эта компоновка предназначена для стенда и контролируемого стояночного теста. Перед использованием в движении нужно согласовать и проверить постоянное место скорости/передачи и видимость штатных предупреждений. Существующее освобождение слоёв при потере критичных данных не отменено.
