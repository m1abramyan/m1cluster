# Первый контролируемый тест на стоящем автомобиле

Версия 0.3.3: одна приборка и настройки iDrive — включение отображения, ожидание двигателя, RU/EN и отдельные единицы. Центральные виджеты удалены. Публичный источник для MGU Store — [m1abramyan/m1cluster](https://github.com/m1abramyan/m1cluster), ветка `main`. Это **source-only**: локально нет настоящего BMW SDK и не получен устанавливаемый автомобильный пакет; Store должен собрать его с настоящим SDK на HU. Наличие исходников не является подтверждением совместимости.

**Обновление 0.3.3 пока проверено только локально.** Владелец самостоятельно установил предыдущий выпуск и сообщил о его работе; версии компонентов и реальные сигналы ассистент не считывал. Этот документ — порядок проверки обновления с отдельным разрешением владельца на каждое действие ассистента с автомобилем. Здесь нет автоматического SSH, поиска машины, установки или перезапуска.

Исходные контракты и зафиксированные SHA: [STORE_RESEARCH.md](STORE_RESEARCH.md). При расхождении установленного Store с исследованной версией сначала уточнить его реальные возможности. Не выполнять прошивку, root-enrollment, fix-key, кодирование, очистку ошибок или переустановку Store.

Для четырёх отсутствующих показателей добавлена страница **«Проверка данных»**; порядок ручного сбора и фотографирования списка — [DIAGNOSTICS.md](DIAGNOSTICS.md). Она не включает автозапуск и не записывает данные в блоки.

## 1. До установки

Автомобиль стоит в безопасном месте, селектор P, стояночный тормоз включён. Для проверки двигателя — подходящее открытое или вентилируемое место. Не включать передачи и не перемещать автомобиль ради заполнения полей. Все неподтверждённые поля остаются недоступными.

Записать без VIN и персональных данных:

- iDrive 7 / HU_MGU, версия ПО и MainApp, реально установленная версия Node; upstream целится в Node 8.16.2.
- Версии MGU Store, mgu-updater, mgu-deploy, mgu-python, единственного cluster-render. Исследованные исходники: mgu-deploy 0.8.18, cluster-render 0.5.9. Это не заявление, что они установлены у пользователя, и не автоматически разрешённое обновление.
- Наличие штатного SDK donor app. Store должен получить настоящий `oap-sdk` на машине; Mac-заглушка недопустима.
- Работа штатной приборки, читаемость штатной скорости/селектора/предупреждений до теста; сохранить описание исходного состояния.
- Возможность вернуться в настройки Retro Cluster и снять флажок **Включить приборку**. Этот путь должен быть доступен до включения нашего слоя.

Для доступа с Mac использовать только текущий подтверждённый адрес автомобиля и существующую ключевую пару вне проекта. Не использовать старый IP из истории. SSH host key сверять; не отключать его проверку и не удалять `known_hosts`. Если доступ не работает — остановиться, не восстанавливать root в рамках этого теста.

## 2. Выключить конкурирующую тему

В уже установленном **Cluster Themes** сохранить текущие настройки, затем выбрать **Off (BMW's own cluster)**. Если включено переключение по drive mode, выключить его или установить Off во всех его режимах. Другие полноэкранные приложения также выключить их собственным штатным выключателем. Не удалять общие зависимости и не останавливать cluster-render.

Убедиться глазами, что штатная приборка вернулась. Если тема не отпускает экран или штатные предупреждения уже закрыты, не продолжать установку/включение Retro Cluster.

## 3. Выбрать источник для Store

Основной путь — публичный GitHub-источник [m1abramyan/m1cluster](https://github.com/m1abramyan/m1cluster), ветка `main`. В Store: **Settings → Add source**, ввести `m1abramyan/m1cluster` или полный адрес репозитория, затем выбрать **main**. Это документированный upstream путь добавления GitHub-репозитория ([MGU Store README, Sources](https://github.com/robertnisipeanu/mgu-store/blob/9c2360a211cfe75fbe4c2b2db86f84a33b380fb9/README.md#sources)). Точное название локализованной кнопки зависит от установленной версии Store. Для публичного репозитория личный GitHub token не нужен.

Перед установкой проверить предлагаемые id `manuk_retro_cluster`, версию **0.3.3** и записать commit SHA, выбранный Store. `main` может изменяться: если Store показывает другую версию/неожиданный commit, сначала сверить состав обновления. Ветку не следует считать неизменяемым эталоном. Не добавлять upstream bimmer-lab/apps вместо нашего источника и не устанавливать весь каталог.

Альтернатива без сетевой загрузки источника в Store — подготовить только наш исходный пакет на Mac.

Из корня проекта:

```sh
python3 tools/source_bundle.py
```

Результат для текущей версии: `dist/manuk_retro_cluster-source-0.3.3.zip`. Это **исходники для Store build**, не готовое устанавливаемое приложение и не файл, который Store должен читать как ZIP.

На USB создать папку `mgu-repo/manuk-retro-cluster/` и распаковать содержимое ZIP так, чтобы `mgu-repo.json` лежал непосредственно в ней:

```text
USB/
  mgu-repo/
    manuk-retro-cluster/
      mgu-repo.json
      apps/manuk_retro_cluster/
      kit/
      shared/
      tools/
      config/
      licenses/
```

Состав конкретного архива проверяется командой сборки и отчётом проекта. В нём не должно быть модуля `oap-sdk` (настоящего или тестовой заглушки), всех исходных приложений, `.git`, приватных ключей, VIN или стендовых данных. Слово `BENCH_STUB` в проверке запрета сборки или документации допустимо: это не поставка самого stub SDK.

Если настоящий SDK уже предоставлен отдельно, локальная автомобильная сборка:

```sh
python3 tools/build.py manuk_retro_cluster
```

Без настоящего SDK отказ этой команды ожидаем и правилен. Не копировать stub из bench в `oap-sdk/` ради обхода. До успешного Store build или сборки с настоящим SDK локального устанавливаемого пакета нет.

## 4. Установить вручную через уже установленный Store

1. Открыть добавленный GitHub-источник `m1abramyan/m1cluster`, ветка `main`, и выбрать только **Retro Cluster**, id `manuk_retro_cluster`, версия **0.3.3**. Для альтернативного USB-пути вставить подготовленный носитель и открыть MGU Store → **USB** → `manuk-retro-cluster`.
2. Проверить список действий и зависимостей. Наш manifest не поручает Store устанавливать cluster-render: существующий renderer и его версию обязательно сверить заранее. Не подтверждать неожиданную установку другого renderer, Waze, переустановку Store, обновление общих инструментов или перезапуск. Если нужной зависимости нет, сначала отдельно согласовать это состояние.
3. Нажать Install только для Retro Cluster. Store соберёт исходники с SDK штатного donor app и зарегистрирует OAP entry point. Дождаться результата. При ошибке сохранить обезличенное сообщение; не повторять установку бесконечно.
4. Убедиться, что это отдельная плитка **Retro Cluster**, оригинальный `cluster_themes` сохранён, итоговый start type — `manually`. Исходное app.json не является доказательством: проверяется итоговый package.json или установочная запись Store.
5. Если Store сообщает, что нужен перезапуск, остановиться. Этот документ не выполняет и не разрешает автоматический restart HU/MainApp.

## 5. Конфигурация и ручной запуск

Поставляемый автомобильный профиль: русский язык, км/ч, °C, bar, л/100 км; отрисовка и ожидание двигателя по умолчанию выключены. Часы 24 часа/Asia/Yerevan **+240 минут** сохранены для архивной Retro; в рабочей приборке часов нет. Demo и угадывание передач запрещены. `redline:7000` и температурные пороги унаследованы как настройки графики, а не подтверждённые ограничения двигателя именно этого автомобиля. Объём бака неизвестен и равен `null`.

Пользовательский файл находится отдельно от кода, в каталоге конкретного OAP uid:

```text
<реальный каталог приложений>/oap_<UID>/data/manuk_retro_cluster.json
```

UID назначает MainApp. Не брать UID другого приложения и не угадывать абсолютный путь. При поиске целевого каталога сверить `source/package.json.name === "manuk_retro_cluster"`. Не собирать полный реестр/содержимое домашней папки в отчёт.

Открыть плитку **Retro Cluster** вручную, пока `enabled:false`. Проверить четыре группы: **Включить приборку**, **Включать при запуске двигателя**, **Язык**, **Единицы измерения**. Выбрать нужные RU/EN и единицы отдельно для скорости, температуры, давления и расхода; для первого теста оставить метрические. Опцию двигателя пока оставить выключенной. Убедиться, что флажок отображения можно снять, затем включить его вручную. Снятие флажка — штатный способ освобождения наших слоёв. Закрытие страницы не является выключением фоновой логики; автоматического открытия настроек нет.

Настройки сохраняются атомарно в указанный data-файл. Перезапуск HU или редактирование файла через SSH для обычного включения, языка и единиц не нужны. Альтернативный локальный способ для проверки или восстановления — подготовка JSON:

Подготовить локальную копию конфигурации (родительский каталог должен существовать; `init` отказывается перезаписывать имеющийся файл), проверить и включить её:

```sh
node tools/config.js --file /absolute/path/to/manuk_retro_cluster.json init
node tools/config.js --file /absolute/path/to/manuk_retro_cluster.json validate
node tools/config.js --file /absolute/path/to/manuk_retro_cluster.json enable
```

Если используется этот альтернативный способ, передать только проверенный JSON в целевой data-каталог отдельным согласованным действием с использованием текущего адреса и обычной проверки SSH host key. При записи на автомобиле использовать временный файл в том же каталоге и rename, сохранить владельца приложения и права. Не заменять исходники и не редактировать CustomAppList вручную. Runtime перечитывает собственный JSON; для включения слоя перезапуск HU не нужен.

Если конфигурация невалидна, не снимать защиту. Если скорость/селектор/жизненный цикл источника недоступны, наша отрисовка должна оставаться освобождённой; не включать Demo для «проверки картинки» в автомобиле.

## 6. Проверка отображения на месте

Зафиксировать результаты отдельно для каждого пункта; отсутствие теста обозначать «не проверено».

| Проверка | Ожидаемое наблюдение |
|---|---|
| Запуск и readiness | Процесс работает; сигналы и renderer готовы раздельно; нет серии повторных стартов |
| Скорость | 0 км/ч в неподвижном автомобиле; данные получены от реального источника |
| Селектор | Только реально полученное P; недоступность не превращается в P/N/D по предположению |
| Обороты | Соответствуют штатному показанию при допустимом состоянии двигателя; ноль не означает отсутствующие данные |
| Масло/охлаждение | Реальные значения в °C либо недоступно; нет стендовых постоянных значений |
| Топливо | Реальный сигнал; неизвестный объём бака не подставлен произвольно |
| Наддув/дополнительные поля | Реальный разрешённый источник либо недоступно; никаких диагностических активных экспериментов |
| Язык и единицы | RU/EN не меняет автомобильные значения; выбранные км/ч/мили, °C/°F, bar/psi и л/100 км/mpg соответствуют числам |
| Центральный экран | После ухода со страницы приборка продолжает работать; штатный интерфейс доступен |
| Статус renderer | Наличие `shown`/`verified` не заменяет проверку глазами |
| Штатные предупреждения | Полностью видны и читаемы там, где ожидаются штатно; наша сцена не закрывает важные обозначения |
| Отключение | Наши слои пропали; после linger общая сцена освобождена, если больше никто её не использует |

Проверять только естественно доступные безопасные предупреждения/индикацию (например, уже отображаемые при включении зажигания). Не провоцировать неисправности, не отсоединять датчики, не отключать системы автомобиля и не менять кодировки. Конкретные предупреждения, которые не удалось увидеть, остаются неподтверждёнными.

Оригинальный Retro — полноэкранный эталон. Геометрия может пересекать штатную индикацию на этой G30. Не сдвигать элементы «незаметно»: если возникает конфликт, выключить отрисовку и записать координаты/наблюдение для отдельного будущего варианта. Даже 1920×720 не гарантирует полной видимости из водительского кресла.

Сценарии потери/возврата сигналов и renderer сначала уже проверяются на стенде. На автомобиле **не убивать BMW-процессы, не перезапускать общий renderer и не отключать блоки ради fault injection**. Естественный сон/пробуждение проверяется отдельным согласованным этапом после успешного выключения.

## 7. Выключение и восстановление

1. Открыть настройки Retro Cluster и снять флажок **Включить приборку** (в EN — **Enable cluster display**). Это сохраняет `enabled:false` и освобождает только наши слои/соединения; не удаляет Store и renderer. Включённая опция двигателя не должна отменять ручное выключение.
2. Проверить глазами исчезновение Retro и возврат штатной скорости, селектора и предупреждений. В исследованном renderer `panel_linger_ms = 3000`, поэтому сам target может отпускаться с задержкой. Не считать истечение трёх секунд доказательством возврата изображения.
3. Альтернативный путь — локально подготовить отключённый JSON и отдельным разрешённым действием атомарно заменить целевой конфиг:

```sh
node tools/config.js --file /absolute/path/to/manuk_retro_cluster.json disable
```

4. Если штатное изображение не вернулось, не ехать. Зафиксировать состояние и прекратить эксперименты. Не пытаться исправить это убийством HMI/MainApp, restart loop, прошивкой или повторной установкой общих сервисов.

При процессе, который уже аварийно завершился, клиентское соединение должно исчезнуть по протоколу; однако реальное возвращение BMW картинки при любом сбое здесь **не гарантируется**.

## 8. Обезличенные логи

Собирать только журнал нашего приложения и выбранные строки Store/renderer, относящиеся к нему и моменту теста. Не копировать все DLT/реестр/донор SDK/конфигурацию Store.

- Из data-каталога взять `manuk_retro_cluster.log` и при необходимости его `.1`, после проверки владельца целевого приложения.
- Для Store сохранить конкретную ошибку сборки/установки и версии инструментов. Не выгружать доступы к источникам, токены и полные debug-архивы.
- Перед отправкой удалить VIN, IP/MAC, ключи, пароли/токены, имена Bluetooth/телефона, адреса/координаты и персональные пути. Сохранить timestamps, названия сигналов, renderer state, текст ошибок и id нашего приложения.
- Если лог содержит неожиданную чувствительную информацию, не отправлять его до удаления этих строк. Приложение не должно логировать значения всех автомобильных сигналов или VIN.

Для уже полученной локальной копии есть помощник, который создаёт новый файл и не перезаписывает оригинал:

```sh
python3 tools/anonymize-log.py --input /absolute/path/manuk_retro_cluster.log --output /absolute/path/retro-redacted.log
```

Он удаляет распространённые шаблоны идентификаторов. Перед отправкой всё равно прочитать полученный файл: имена, географию, нестандартные форматы секретов и персональные сообщения нельзя надёжно исключить одной регулярной проверкой. Эта команда не получает логи из автомобиля и никуда их не отправляет.

## 9. Удалить только наше приложение

Сначала выключить слой и убедиться в возврате штатной приборки. Сохранить нужный пользовательский JSON: обычный update сохраняет data, но uninstall удаляет его.

MGU Store → Retro Cluster → Remove → **Remove**. Если есть дополнительная кнопка **Remove all**, её не выбирать: она может удалить общие инструменты. Сверить id `manuk_retro_cluster`. Не удалять `cluster-render`, mgu-deploy, mgu-python, MGU Store и оригинальный Cluster Themes.

Документированная upstream альтернатива для отдельного осознанного запуска **на HU**:

```sh
/var/opt/mgu-deploy/mgu-deploy.sh uninstall manuk_retro_cluster --yes
```

Эта команда в рамках локальной разработки не выполнялась. Не путать её с `mgu-install.js uninstall`, `remove-all` или `restore`: у них другой, более широкий охват. При требовании отдельного restart остановиться и согласовать дальнейшее действие.

## 10. Проверка ожидания двигателя и системный автозапуск

После успешного ручного включения и выключения отдельно проверить флажок **Включать при запуске двигателя**. Он сохраняет `startup.onEngineStart`, но **не меняет install-time `mguAppStartType`**. В manual-пакете приложение сначала открывается вручную; пока процесс работает, опция ждёт подтверждённое прямое `engineRunning:running`. Уже работающий двигатель при первоначальном снимке подходит. RPM, температура и общий режим не заменяют это состояние.

В текущей активной сессии достоверная остановка start-stop не сбрасывает разрешение. Неизвестное состояние, потеря источника, сон, остановка процесса и ручное выключение сбрасывают его. После штатного завершения manual-процесса потребуется новый ручной запуск. Проверить естественные состояния только разрешёнными действиями на стоящей машине; не имитировать аварии или отключение провайдера. Детали и локальные тесты — [AUTOSTART_SETTINGS.md](AUTOSTART_SETTINGS.md).

После подтверждённых ручного запуска, disable, возврата штатной приборки и сохранения настроек можно отдельно подготовить пакет с `mguAppStartType: "autostart"`. В исследованном Store этот флаг применяется при install/update из итогового package.json; изменение одного runtime JSON его не включает. Для отдельно предоставленного настоящего SDK проектный builder поддерживает явный opt-in и требует более новую версию, например:

```sh
python3 tools/build.py --autostart-after-manual-test --version 0.3.4 manuk_retro_cluster
```

Это команда будущего этапа, а не часть первого теста. При отсутствии настоящего SDK она обязана отказать. Текущий Store source manifest собирает manual 0.3.3; GitHub-источник или USB-пакет не превращается в autostart от изменения runtime-конфига или флажка двигателя. Для source-only autostart потребуется отдельно подготовленная новая версия исходников/manifest.

До этого момента все source/vehicle packages должны оставаться `manually`. Для изменения режима потребуется новая версия, проверка итогового архива и отдельное явное разрешение установки. Автозапуск также требует отдельной проверки сна/пробуждения и отсутствия удержания автомобиля активным. Для отключения автозапуска — следующий manual package update; `enabled: false` сразу выключает слои, но не меняет start type менеджера.

**Дорожные испытания не рекомендованы, пока на этом автомобиле не подтверждены реальная читаемость скорости, передач, штатных предупреждений и надёжное выключение собственной отрисовки.** Успешный Mac-стенд не закрывает эти пункты.

## Локальная подготовка логов к передаче

После копирования только собственного журнала приложения в локальную папку вне Git:

```sh
python3 tools/anonymize-log.py --input /absolute/path/manuk_retro_cluster.log --output /absolute/path/retro-sanitized.log
```

Команда не соединяется с автомобилем, не меняет исходный журнал и отказывается перезаписывать результат. Она удаляет распространённые VIN/ID, адреса, пути пользователей и секреты. Перед передачей вручную просмотрите оставшийся текст: автоматическая очистка не гарантирует распознавание всех личных сведений.

## Дополнительная проверка данных 0.3.1

До включения графики можно выполнить отдельно разрешённую ограниченную [read-only проверку источников](READ_ONLY_SIGNALS.md). Нет необходимости искусственно выключать DSC или провоцировать вмешательство: неизвестные значения остаются прочерком. Режим, профиль двигателя, программа коробки и DSC сверяются раздельно. Например Sport с D и штатно включённым DSC должен оставаться именно таким сочетанием. Отдельного источника профиля ENGINE сейчас нет; его строка удалена. Прямое состояние engineRunning используется только для ожидания двигателя и не является профилем настройки двигателя. Предупреждения приложения должны отличаться от обычного акцента Sport; штатные предупреждения проверяются отдельно без дорожных испытаний.

Проверить фактическое название FES и переходы только доступными штатными действиями на стоящей машине. MDrive S/M может отсутствовать на 540i. Подпись «КПП:D» может обозначать подтверждённое положение селектора D; она не доказывает отдельно прочитанную программу D. Номер передачи никогда не выводится из скорости/RPM. Отсутствующий расход/наддув/путь BC ожидаем, пока не проверены масштаб и единицы. TPMS остаётся только предметом read-only проверки, его центральный виджет удалён. После сна требуются новые наблюдения, вчерашние состояния не восстанавливаются из конфигурации.
