# Retro Cluster 0.3.1

Самостоятельное приложение `manuk_retro_cluster` для iDrive 7 / HU_MGU, название в списке — **Retro Cluster**. Источник для MGU Store: **https://github.com/m1abramyan/m1cluster**, ветка **main**.

**Версия 0.3.1 на автомобиле ещё не проверена.** Владелец сообщил об успешной установке 0.3.0 и задержке смены оформления; реальные сигналы и версии компонентов ассистент не считывал. В репозитории поставляются исходники для сборки через Store: проприетарного BMW SDK в проекте нет. Store собирает приложение с настоящим SDK своего donor app. Первый тест — ручной запуск на стоящем автомобиле. Подключений к автомобилю, установки, перезапуска MGU и кодирования эта разработка не выполняет.

## Изменения 0.3.1

Обычная смена режима обновляет только строку режима/DSC: повторные изображения цифр и шкалы RPM не отправляются. В локальном сравнении шесть переключений передали на 90,36% меньше image-данных, изображения трёх профилей совпали побайтно. Это не измерение скорости MGU. Исправлен порядок сигналов: старый ответ getter не может заменить более новое уведомление того же поля.

Выпуск остаётся **ручным**. Расход л/ч, наддув, DSC и процент топлива без подтверждённой ёмкости не получают угаданные значения; улучшена диагностика причин отсутствия. При 100 °C шкала масла имеет 10 ярких и 5 тёмных сегментов: тёмная верхняя часть сама по себе не означает потерю слоя. [Отчёт 0.3.1](docs/RELEASE_0.3.1.md).

## Что входит

Одна приборка 1920×720: скорость, фактическая передача и подпись КПП, режим/DSC, расход, запас хода, топливо, масло, охлаждение и наддув. Центральные виджеты удалены; скорость и передача остаются на экране. Для недоступных источников используются прочерки, автоматической симуляции в автомобильной версии нет.

Основа — Retro 80s из [bimmer-lab/apps](https://github.com/bimmer-lab/apps/tree/aaa43e49500ccb4cd6b07537644ac072db49eb99), SHA `aaa43e49500ccb4cd6b07537644ac072db49eb99`. Оригинальные DSEG-атласы сохранены; русские подписи используют лицензированные атласы Roboto Condensed. Все закреплённые версии и контрольные суммы — в [UPSTREAM.lock.json](UPSTREAM.lock.json).

Общая белая основа, цветное название режима, тахометр до 8000 с 40 ячейками по 200 об/мин: белый до 6000, жёлтый после 6000, красный после 7000. При достоверных оборотах от 7000 шкала мигает красным с частотой 2 Гц. Это выбранный порог оформления, а не подтверждённый предел двигателя. Боковые шкалы — по 15 сегментов. Синяя полоса холодного ограничения подготовлена, но скрыта: подтверждённого источника в исследованных исходниках нет.

## Стенд одной командой

Нужны Node и Python 3. Из корня проекта:

```sh
npm run bench
```

- [Приборка и имитация данных](http://127.0.0.1:8078/).
- [Экран настроек iDrive](http://127.0.0.1:8078/idrive).

Сервер слушает только loopback. Изменения исходников автоматически пересобирают приложение. Остановка — Ctrl+C. Здесь работают тот же код приложения, layout, атласы и GLSL, что в автомобильной сборке; подменены источники данных и транспорт renderer. Настройки iDrive показываются через локальный RHMI-предпросмотр с настоящими обработчиками приложения; это не снимок реального экрана BMW.

## Настройки iDrive

На странице приложения доступны:

1. **Включить приложение** — разрешает отрисовку; выключение освобождает наши слои.
2. **Включать при запуске двигателя** — уже запущенный процесс ждёт подтверждённого сигнала работы двигателя. Не использует таймер или обороты для угадывания запуска.
3. **Язык** — русский / английский для страницы и приборки.
4. **Единицы** — независимо: км/ч или mph, °C или °F, bar или psi, л/100 км или MPG US. На стоянке л/ч / gal/h выводятся только при наличии отдельного источника расхода.

Изменения сохраняются атомарно в собственном `data/manuk_retro_cluster.json`, отдельно от поставляемого кода, и переживают обычное обновление. Схема 7 переносит настройки версий 1–6, удаляя отменённый выбор виджета. Полная [конфигурация](docs/CONFIGURATION.md), [схема](config/schema.json), [автомобильный пример](config/car.example.json).

**Ограничение запуска:** первый пакет имеет `mguAppStartType: manually`, `enabled: false`, `onEngineStart: false`. Флажок двигателя не меняет политику запуска процесса Store. После полного выключения автомобиля ручной пакет снова нужно открыть вручную. Полноценный фоновый автозапуск требует отдельного пакета/обновления после проверки выключения и восстановления штатной приборки. Подробности — [AUTOSTART_SETTINGS.md](docs/AUTOSTART_SETTINGS.md). Страница настроек сама поверх штатного интерфейса не открывается.

## Установка через существующий MGU Store

В Store добавить GitHub-источник `m1abramyan/m1cluster`, выбрать канал ветки **main**, затем только **Retro Cluster** (`manuk_retro_cluster`, 0.3.1). Источник использует стандартный `mgu-repo.json` и `tools/build.py`; публичному репозиторию не нужен GitHub-токен для чтения. Формат описан в [Store Publishing](https://github.com/robertnisipeanu/mgu-store/blob/main/docs/PUBLISHING.md).

До установки сверить настоящий SDK donor, версии Store и имеющегося cluster-render. Мы используем существующий renderer; второй сервис не поставляется. Не подтверждать неожиданные общие обновления или перезапуск MGU. Полная последовательность установки, выключения, удаления только приложения и проверки штатных предупреждений — [FIRST_CAR_TEST.md](docs/FIRST_CAR_TEST.md).

Исходный архив для USB создаётся так:

```sh
npm run bundle:source
```

Архив `dist/manuk_retro_cluster-source-0.3.1.zip` нужно распаковать в `USB/mgu-repo/manuk-retro-cluster/`, сохранив `mgu-repo.json` в корне этой папки. Это исходники, не устанавливаемый бинарный пакет.

```sh
npm run build:car
```

Команда выше **отказывается собирать** без настоящего SDK или при обнаружении тестовой заглушки. В стенде заглушка применяется только для явно маркированной локальной сборки, без выпуска `.tgz`/`.mgu`.

## Проверки

```sh
npm ci
npm test
npm --prefix bench ci
node bench/verify-idrive.js
```

Последняя команда проверяет отдельно запущенный стенд; параметры и изоляция описаны в [bench/README.md](bench/README.md). `npm test` включает конфигурацию/миграцию, независимые единицы, действия RHMI, отказ сохранения, engine gate, lifecycle, потерю данных, восстановление renderer, оригинальные хеши ресурсов, итоговый манифест и запрет пакета с заглушкой. [Отчёт версии 0.3.1](docs/RELEASE_0.3.1.md) отделяет фактически выполненные проверки от ограничений; [0.3.0](docs/RELEASE_0.3.0.md) сохранён как история.

На Mac arm64 используется Node 24.21.0. Цель автомобиля — Node 8.16.2. Выполняется статическая проверка синтаксиса ES2017 и используемых API; фактическое исполнение на Node 8 здесь не подтверждено (бинарник x64 не запускается, Docker недоступен). Успех стенда не равен совместимости с MGU.

## Достоверность и первый тест

[Карта источников](docs/DATA_SOURCES.md), [проверка спорных сигналов только чтением](docs/READ_ONLY_SIGNALS.md), [синяя полоса RPM](docs/COLD_RPM_SIGNAL.md), [геометрия](docs/LAYOUT_PROFILES.md). Реальных данных этой G30 во время разработки не читалось. Отдельный профиль двигателя, DSC, мгновенный расход, масштаб наддува и некоторые шкалы BC требуют проверки; предполагаемые значения не выдаются за реальные.

Полноэкранная Retro может закрывать штатные предупреждения. Это не исправляется предположениями о видимой области G30. Перед движением нужно на стоящем автомобиле подтвердить видимость штатной скорости/предупреждений, реальные показания, отключение приложения и возврат штатного изображения. До этого дорожные испытания не рекомендуются. Нет обещания возврата штатной картинки при любом сбое.

Архивные `reference_retro.png`, `retro_cluster.png`, `diff.png` относятся к исходной английской Retro с одинаковыми фиксированными данными: прежнее сравнение дало 0 отличающихся пикселей. Это не сравнение обновлённой компоновки. Отменённые виджеты и предыдущие отчёты сохранены только как история разработки.

## Файлы и лицензии

`apps/manuk_retro_cluster/` — самостоятельное приложение; `shared/` и `kit/` — закреплённые зависимости; `bench/` — локальный стенд; `tests/` — проверки; `config/` — схема и примеры; `docs/` — источники и инструкции. `upstream/` служит локальным эталоном и не публикуется. Иконка `icon.png` использует оригинальные семисегментные цифры и цвета тахометра; рецепт — `tools/make-app-icon.py` (Python с Pillow).
